# Character asset authoring

The asset boundary accepts two deliberately small Blender-to-GLB paths: a baked
static preview and a one-skin character with one looping transform clip. Neither
is a general scene loader.

## Blender convention

Author in metres using Blender's native Z-up coordinates, with the character
facing Blender `-Y`. Blender's exporter converts that to the runtime contract:
Y up and `+Z` forward. Keep the preview as one mesh object, one material and one
embedded RGBA PNG base-colour texture. Apply object transforms when they are
part of the mesh; ordinary parent node translation, rotation and scale are also
accepted and baked once at import.

The material must be opaque and have **Backface Culling** enabled. Use one UV
map and the default repeat-wrapped Image Texture node connected to Principled
BSDF Base Color. Scalar Metallic and Roughness values are accepted but
deliberately normalized away: this checkpoint renders a lit base colour, not
PBR surface response. Normal, occlusion, emissive and metallic-roughness
textures remain unsupported and are rejected.

Export as glTF 2.0 with:

- Format: **glTF Binary (`.glb`)**
- Include: the selected mesh only, with cameras and lights disabled
- Data: UVs and normals enabled; animations, skinning and shape keys absent
- Images: PNG

Blender's GLB exporter writes a trilinear sampler. The importer validates that
request and builds the complete mip chain in linear colour space; the GPU then
samples it through an sRGB texture. This avoids shimmering and preserves colour
when the pulled-out camera reduces many texels into one.

## Reproducible compatibility fixture

The checked-in `assets/fixtures/blender-static-preview.glb` is generated by
Blender rather than assembled by the engine's diagnostic fixture writer. From
the repository root:

```text
blender --background --python assets/fixtures/generate-blender-static-preview.py
```

The script uses ordinary mesh objects, UV maps, a Principled material, a packed
PNG and Blender's normal GLB exporter. The resulting asymmetric, metre-scale
training dummy is the authoring-workflow gate. The hand-written
`static-preview.glb` remains the smaller arithmetic and orientation diagnostic.

## Bind-pose character

The skinned path keeps the same unit, facing, material, UV and texture rules,
but the mesh must be controlled by one armature. Give every retained object and
bone a non-empty, unique name. The accepted subset is one mesh primitive, one
rooted node tree, one skin of at most 64 joints, and exactly four joint-index and
weight lanes per vertex. Zero-weight lanes are fine; the nonzero weights must be
finite and sum to a positive value. The importer normalizes them once.

Apply the mesh object's location, rotation and scale before export so its global
node transform is identity. Bone transforms remain authored hierarchy data and
must not be applied to the mesh. This division is deliberate: the skeleton
produces asset-local poses, while the app's `Instance` is the only placement,
scale and facing transform used by the renderer.

Export the selected mesh and armature together as a binary GLB with UVs, normals,
skinning and one active action enabled. Keep shape keys, cameras, lights and glTF
extensions disabled. Blender must emit inverse bind matrices;
the importer rejects a skin whose bind-pose palette does not reproduce every
authored vertex.

The action must have a non-empty unique name, two to 256 keys per channel, a
duration no longer than 60 seconds, and matching start/end times across every
channel. The emitted glTF may use `LINEAR` or `STEP`; Blender commonly exports
motion as `LINEAR` and unchanged components as `STEP`. Cubic splines, morph
targets, non-joint targets and non-uniform scale are rejected explicitly. Key
the bind pose at both ends when the clip should loop without a seam.

The checked-in `assets/fixtures/blender-bind-pose.glb` exercises this contract
with a three-bone, asymmetric training dummy and a one-second `Sway` action.
Regenerate it from the repository root with:

```text
blender --background --python assets/fixtures/generate-blender-bind-pose.py
```
